# Инструкции проекта

- Общение, комментарии и документация — на русском языке.
- Распознавание и редактор работают локально, без телеметрии. Сеть разрешена только менеджеру моделей по явному действию пользователя, из закреплённых публичных источников с SHA-256. Не отправлять аудио или транскрипции.
- Большие записи читать блоками. Номера спикеров должны сохраняться между блоками.
- Исходное аудио не изменять и не удалять.
- Исходные проверенные модели лежат в `models/`; лёгкая сборка использует библиотеку пользователя в Application Support/Голоса/Models. Не добавлять модели и личные данные в Git.
- Перед выпуском проверять обе модели, диаризацию, отмену и переносимость готовой сборки.
