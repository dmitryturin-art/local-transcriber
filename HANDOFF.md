# Состояние: Голоса 1.2.0 — 9 октября 2026

Не использовать Computer Use, не открывать приложения и не управлять мышью/клавиатурой без отдельной прямой просьбы пользователя. Ранее UI-автоматизация сопровождалась нестабильным вводом; выход из desktop ChatGPT восстановил управление. Точная причина не установлена. Все дальнейшие проверки выполнялись без GUI.

## Последние изменения

- Приватный репозиторий создан в личном аккаунте dmitryturin-art: https://github.com/dmitryturin-art/local-transcriber . Пользователь прямо разрешил создать и выложить проект; аккаунт подтверждён как User и совпадает в gh и подключённом GitHub.
- Новая сборка отдельно: dist/release-1.2/Голоса.app и Голоса-1.2.0-AppleSilicon.dmg. Не заменять/удалять запущенную пользователем 1.1 до завершения его проверки.
- Лёгкий DMG около 124 МБ. Модели не включены; первый запуск предлагает GigaAM или Parakeet. Можно позже добавить вторую. Whisper отложен.
- ModelManager: публичные закреплённые источники, SHA-256, прогресс, пауза/возобновление, импорт, удаление в Корзину. Общие модели диаризации загружаются один раз. Модели пользователя уже импортированы в ~/Library/Application Support/Голоса/Models.
- Процесс распознавания остаётся с системным запретом сети; сеть только для явной загрузки модели. Не отправлять записи, транскрипции или voiceprints в GitHub.
- Диаризация общая Pyannote + CAM++, не зависит от GigaAM/Parakeet. Старое авто дробило голос на маленькие кластеры: добавлены оценка silhouette и минимальная поддержка группы. На 1024 репликах записи вместо 8 выбран 2.
- Существенно изменён поток: один проход ASR по объединённым участкам речи, времена слов, сопоставление с временными участками голосов. Убирает повторное ASR перекрывающихся клипов. Короткие реплики используют также стабильный локальный голос. При неопределённости выводится неизвестный спикер; RNNT-тайминги приблизительны, ошибки остаются.
- Пользователь сообщил, что даже фиксированные 2 спикера в старой версии смешивали фразы. Не утверждать, что это полностью решено. Нужна пользовательская оценка по прослушиванию, автоматического достоверного эталона нет.
- Полная новая обработка 1:34:30: 2 спикера, 867 реплик, 225 неопределённых, 667 неуверенных, около 362 с. Это консервативная разметка, требующая проверки.
- Добавлены объединение групп с undo, переназначение отдельных реплик, пересчёт по voiceprints без повторного ASR. Старые результаты требуют исходной записи.
- Исправлены цвета спикеров в тексте. Отображение можно переключить отдельно от обработки.
- Одновременно сохраняются TXT/MD/SRT со спикерами и transcript.no-speakers.* плюс JSON и локальный voiceprints.npz.
- Ожидаемый язык ru/en/auto. Parakeet получает язык через API, но жёсткое ограничение не гарантируется. Неподходящие слова отмечаются, не подменяются. GigaAM ориентирован на русский.

## Проверки

13 тестов backend, 36 проверок редактора, реальная загрузка небольшого файла GitHub и SHA-256, импорт обеих моделей и повторный запуск. Публичный декодер/joint GigaAM совместимы с локальным энкодером; большой энкодер повторно не скачивали. Полная длинная запись обработана; короткий фрагмент проверен обеими моделями. Собранные GigaAM и Parakeet проверены через контроллер без GUI. Пересчёт из voiceprints без аудио сохранил текст и времена. DMG и подпись проверяются при выпуске.

## Далее

Пользователь должен оценить 1.2 по реальной записи; возможна дальнейшая работа над границами/достоверностью спикеров. Времена GigaAM приблизительные. Модели и build/ исключены из Git. Личные аудио и тексты находятся вне проекта и не публикуются.

## Версия 1.3.0

Для будущих тестов распознавания использовать первые 45 минут, отдельный фрагмент в workspace work/test-first-45min.m4a. Личные записи никогда не добавлять в Git.

## Версия 1.4.0
Название транскрипции редактируется вверху редактора или через «Переименовать» в «Моих транскрипциях». Имя исходника не меняется. Название в редакторе сохраняется вместе с правками, в списке — кнопкой сохранения названия. «По спикерам / Сплошной текст» меняет просмотр и копирование; временные метки сохраняются, в сплошном тексте скрыты имена, предупреждения и отметки проверки. Совпадения поиска подсвечиваются жёлтым; крестик очищает запрос. Активный поиск скрывает остальные реплики.
Папка сохранения перенесена в «Голоса → Настройки…». Из редактора убраны лишние папки; «Открыть папку с результатами» доступно в меню действий конкретной записи в библиотеке. «Экспорт…» сохраняет выбранный TXT/Markdown/SRT со спикерами или без них; учитывает текущие правки. JSON, резервные копии и голосовые признаки находятся в «Служебных данных». Старые результаты читаются без преобразования аудио; при сохранении служебные файлы переносятся автоматически. Распознавание заново не требуется. Пометка сомнительного голоса: «Проверьте спикера». Интерфейс и меню настроены на русский язык. GUI и колонки пользователя агент не проверяет и мышью не управляет.
