# Текущее состояние — Голоса 1.1.0, 9 октября 2026

## Важное ограничение

Не использовать Computer Use и не управлять мышью/клавиатурой без отдельной прямой просьбы пользователя. Ранее после UI-автоматизации ввод в других приложениях стал нестабильным. Пользователь сообщил, что выход из desktop-приложения ChatGPT восстановил ввод; после повторного запуска разрешил продолжить. Точная причина не установлена. В этом продолжении все проверки выполнялись программно, без открытия окон и захвата экрана.

## Готово

- Автономное приложение macOS «Голоса», Apple Silicon, цель macOS 14+.
- GigaAM v3 E2E с пунктуацией и Parakeet v3 Q8_0. Модели скопированы/экспортированы из уже скачанных файлов. Handy и внешний кэш для запуска не нужны.
- Диаризация: 1–8 спикеров либо авто; единые номера по всей записи. Длинные файлы читаются блоками, используются RF64 и общая кластеризация.
- TXT, Markdown, SRT и JSON. Таймкоды, имена, перекрытия, отметки неопределённого голоса.
- Нативный редактор реплик и спикеров; добавление участника; отмена/повтор; резервные transcript.original.*; сохранение правок во всех форматах.
- Массовая замена с предпросмотром, регистром и целыми словами. Буквальная вставка специальных символов. Поиск по тексту и фильтр непроверенных участков.
- Локальный словарь исправлений. Автоматическое применение выключено по умолчанию, включается пользователем.
- Рабочий процесс запускается с системным запретом сети. FFmpeg собран локально из включённых исходников, без сетевой поддержки и Homebrew-зависимостей.
- Приложение и новый DMG 1.1.0 лежат в dist/. Версия DMG теперь соответствует приложению, включая запрет сети и редактор. Старый DMG 1.0.0 оставлен как предыдущая сборка.

## Проверки

- Полная запись 1:34:30 обработана с двумя спикерами и пунктуацией за 406,6 с (базовая версия; движок после этого не менялся).
- 35 проверок редактора прошли: Unicode, предпросмотр, undo/redo, спикеры, исходник, все экспорты, неизвестные поля JSON и безопасные старые привязки.
- Проверка на длинной транскрипции: 969 реплик; предпросмотр, замена и отмена примерно за 5 мс; файл не изменён.
- Настоящий контроллер приложения проверен отдельно с GigaAM и Parakeet: распознавание → правки → экспорт → повторное открытие. Проверки без GUI.
- 8 тестов движка прошли; отмена и режим без спикеров проверены ранее.
- Конвертация 11 форматов проверена: AAC, AIFF, CAF, FLAC, M4A, MP3, OGG, OPUS, WAV, WEBM, WMA.
- Подпись .app и контрольная сумма DMG проверяются при выпуске. Все включённые бинарники требуют не выше macOS 14.0, внешних зависимостей от пользовательских папок нет.

## Следующий шаг

Пользователь может самостоятельно открыть dist/Голоса.app или установить DMG и оценить интерфейс. Физические клики по финальному редактору агентом не проверялись, поскольку запрещено возобновлять управление экраном. При необходимости исправить конкретные замечания пользователя.

GitHub остаётся отложенным. Предыдущая отправка была отклонена автоматической проверкой назначения внешнего экспорта; пользователь разрешил пока не отправлять. Не пушить без нового разрешения с конкретным назначением. Исходники коммитятся локально; модели, бинарники, build/ и личные записи не входят в Git.
