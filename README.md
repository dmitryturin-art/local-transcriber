# Голоса — локальный транскрибатор для macOS

Приложение для расшифровки аудио и видео с пунктуацией, временными метками и разделением по спикерам. Нативный интерфейс на русском языке: без терминала и локального сервера. Записи и текст обрабатываются на компьютере; интернет нужен только для загрузки выбранных моделей.

**Актуальная версия: 1.4.0.** [Установщик и описание выпуска](https://github.com/dmitryturin-art/local-transcriber/releases/tag/v1.4.0) · [История изменений](CHANGELOG.md).

## Установка

1. Скачайте `Голоса-1.4.0-AppleSilicon.dmg` из Releases. Репозиторий закрытый: доступ к выпуску имеют пользователи с доступом к репозиторию.
2. Откройте DMG и перенесите «Голоса» в «Программы». При обновлении сначала закройте предыдущую версию и замените приложение.
3. При первом запуске выберите GigaAM или Parakeet в «Управлении моделями». Можно скачать одну модель и добавить вторую позднее либо импортировать уже скачанные файлы.

Сборка предназначена для **macOS 14 и новее на Apple Silicon**. Intel и Windows не поддерживаются. Проверки выполнены на Apple M4; отдельной проверки на macOS 14 не проводилось.

Приложение подписано ad-hoc, без нотарификации Apple. На другом Mac после скачивания может потребоваться разрешить запуск через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» после первой попытки открытия.

Модели не входят в установщик, кроме небольшого токенизатора и конфигурации. Они хранятся в `~/Library/Application Support/Голоса/Models`; обновление приложения не требует повторного скачивания. Менеджер показывает прогресс, поддерживает паузу/продолжение, импорт и удаление моделей. Удалённую модель можно скачать снова. Общие компоненты разделения голосов загружаются один раз. Handy для работы не нужен.

## Быстрый старт

1. Выберите или перетащите запись в блок «Запись».
2. Выберите GigaAM v3 для русского языка или Parakeet v3 для многоязычной речи. Обе модели поддерживают пунктуацию.
3. Укажите ожидаемый язык. Для диалога включите разделение по спикерам и задайте число участников, если оно известно.
4. Нажмите «Расшифровать». Папка результатов выбирается один раз в «Голоса → Настройки…».
5. После обработки задайте название транскрипции, имена участников и при необходимости исправьте реплики. Нажмите «Сохранить правки» или ⌘S.
6. Скопируйте выбранный вид текста либо нажмите «Экспорт…» и выберите TXT, Markdown или SRT, со спикерами или без них.

Поддерживаются распространённые аудио- и видеоформаты, включая M4A, MP3, WAV, AAC, OGG/OPUS, FLAC, AIFF, CAF и WMA. Файлы диктофонов и мессенджеров принимаются с любым расширением; возможность чтения определяется встроенным FFmpeg. Справка доступна по кнопке «?» и в меню «Справка».

## Просмотр и редактор

- Название редактируется над текстом или через «Переименовать» в «Моих транскрипциях». Исходное имя файла сохраняется отдельно; аудио не переименовывается.
- «По спикерам / Сплошной текст» меняет просмотр и копирование. В сплошном тексте остаются время и абзацы, скрываются имена и служебные отметки.
- Плеер внизу содержит паузу, временную шкалу и подсветку текущей реплики. Нажатие на время реплики запускает запись с этого места. При первом прослушивании создаётся временный WAV. «Следовать за звуком» включает автопрокрутку, которая приостанавливается во время редактирования.
- Поиск подсвечивает совпадения жёлтым и показывает только найденные реплики. Крестик очищает запрос. Если переход по времени не виден, проверьте, не включён ли поиск или фильтр.
- «Проверьте спикера» означает сомнение в назначенном участнике. «Спикер не определён» — участник не назначен. «Одновременная речь» — возможное пересечение голосов.
- Галочка справа — ручная отметка «Проверено мной»: реплика исчезает из фильтра «Требуют проверки». Отметка не обучает модель.
- «Редактировать» позволяет менять текст и участника отдельной реплики. Доступны отмена и повтор правок; временные метки сохраняются.
- «Найти и заменить» показывает предварительный просмотр. Поддерживаются регистр и границы слов. Локальный словарь хранит повторяющиеся замены; автоматическое применение включается отдельно.
- «Спикеры» позволяет объединять номера или пересчитывать назначения без повторного распознавания текста. Названия участников после пересчёта могут потребовать повторного назначения.

Имена и текст сохраняются без повторной обработки аудио. Enter в поле имени не запускает распознавание. История отмены хранится в памяти до закрытия транскрипции; перед первым сохранением правок создаются резервные копии.

## Библиотека, сохранение и экспорт

«Мои транскрипции» показывает результаты выбранной папки сохранения: поиск по названию и исходному имени, открытие, переименование, удаление в Корзину. В меню действий записи находится «Открыть папку с результатами». Исходное аудио при удалении результата сохраняется.

Для каждого запуска создаётся отдельная папка:

- `transcript.txt`, `transcript.md`, `transcript.srt` — текст со спикерами;
- `transcript.no-speakers.txt`, `.md`, `.srt` — варианты без спикеров, с временными метками;
- `Служебные данные/transcript.json` — документ для повторного открытия и редактирования;
- `Служебные данные/transcript.original.*` — резервные копии до первых правок;
- `Служебные данные/voiceprints.npz` — локальные признаки голосов для пересчёта.

Старые результаты открываются без повторного распознавания. При сохранении их служебные файлы переносятся в подпапку. JSON из другой папки можно открыть через меню «Файл» или библиотеку. Для прослушивания при необходимости выберите исходную запись повторно; её путь запоминается локально.

«Экспорт…» сохраняет отдельный файл выбранного формата и варианта в указанное вами место, включая текущие правки. JSON, резервные копии и признаки голосов не нужны для передачи готового текста другим людям.

## Модели и точность

GigaAM v3 E2E работает через ONNX Runtime. Parakeet TDT 0.6B v3 Q8_0 — через transcribe.cpp с Metal или CPU. Разделение голосов выполняется отдельно от распознавания текста: Pyannote segmentation 3.0 + CAM++ через Sherpa-ONNX. Используется Silero VAD.

Источники, версии и SHA-256 закреплены в [model-catalog.json](model-catalog.json): GigaAM ONNX из Hugging Face istupakov, Parakeet из handy-computer, компоненты голосов из выпусков Sherpa-ONNX. Аккаунт Hugging Face не нужен. Сеть разрешена менеджеру моделей только при явном скачивании; рабочий процесс распознавания запускается с запретом сети.

Диаризация может ошибаться даже при заданном числе участников, особенно на коротких репликах, похожих голосах, тихой или одновременной речи. Указание ожидаемого языка Parakeet не гарантирует отсутствие чужих слов: сомнительные места отмечаются для проверки. Таймкоды GigaAM приблизительны. Проверяйте важные фрагменты по исходному аудио.

## Длинные записи

Для распознавания аудио преобразуется во временный WAV на диске и читается блоками по пять минут с контекстом. Речевые фрагменты ограничены 25 секундами и разрезаются по тихим местам. Голоса объединяются по всей записи; номера сохраняются между блоками. Для кластеризации используется не более 1200 репрезентативных образцов.

Временное аудио распознавания занимает примерно 115 МБ на час, отдельно от исходника и результата. Для плеера создаётся WAV 24 кГц — около 173 МБ на час. Кнопка отмены завершает обработку и очищает её временные данные. Возобновления прерванного распознавания с середины пока нет. Исходная запись не изменяется.

## Разработка

Исходники интерфейса находятся в `macos/`, движка — в `backend/`. Сборщик включает Python, зависимости и самостоятельно собранный FFmpeg; установленный Homebrew/Python для запуска приложения не нужен. Веса моделей в DMG не включаются. Атрибуция и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md), `licenses/`; они также входят в приложение.

Для сборки нужны Command Line Tools/Xcode со Swift, Python 3.14, `uv` и зависимости из `requirements.txt`. В `models/gigaam-e2e` нужны проверенные небольшие `features.json` и `tokenizer.model`.

```sh
uv venv --python 3.14 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python scripts/build_media.py
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
.venv/bin/python scripts/check_editor.py
.venv/bin/python scripts/build.py --python .venv/bin/python --dmg
```

Результат сборки: `dist/release-1.4/Голоса.app` и `dist/release-1.4/Голоса-1.4.0-AppleSilicon.dmg`. Для пересборки интерфейса существующей сборки можно использовать `--skip-engine`.

Проверки 1.4: 51 проверка редактора, названий, экспорта, поиска и совместимости; 14 проверок backend; обработка короткого диалога с обеими моделями, диаризация, сохранение, повторное открытие и отмена. Подпись приложения и целостность DMG проверены. Плеер версии 1.3 проверен пользователем; визуальная проверка нового интерфейса и проверка на других Mac отдельно не проводились.
