# Голоса — локальный транскрибатор для macOS

Отдельное приложение для аудио и видео: GigaAM v3 E2E или Parakeet v3, с разделением реплик по спикерам. Запускается двойным кликом, работает без терминала, сервера и интернета. Движки входят в сборку; выбранные модели загружаются при первом запуске либо импортируются из локальной папки.

## Модели

Установщик 1.2 лёгкий. При первом запуске выберите GigaAM E2E или Parakeet в разделе «Модели». Можно загрузить только одну и позже добавить вторую. Общие компоненты диаризации загружаются один раз. Есть прогресс, пауза/продолжение, проверка SHA-256 и импорт уже скачанных файлов. Модели находятся в `~/Library/Application Support/Голоса/Models`. Включённый маленький токенизатор и конфигурация не требуют отдельной загрузки.

Источники публичные, версии и контрольные суммы зафиксированы в `model-catalog.json`: GigaAM ONNX из Hugging Face istupakov, Parakeet Q8_0 из handy-computer, компоненты диаризации из официальных выпусков Sherpa-ONNX на GitHub. Используется та же GigaAM E2E, но готовый публичный ONNX-экспорт; импорт принимает также проверенный локальный экспорт предыдущей версии. Приложение не требует аккаунта Hugging Face/GitHub. Интернет используется только для явной загрузки моделей; процесс распознавания по-прежнему запускается с запретом сети.

## Как пользоваться

1. Откройте `dist/release-1.2/Голоса.app` или установите его из DMG в «Программы».
2. Выберите или перетащите запись. Поддерживаются M4A, MP3, WAV, OGG/OPUS, AAC, FLAC, AIFF, CAF, AMR, WMA и распространённые видеоформаты. Можно выбрать файл с любым расширением; содержимое проверяет FFmpeg.
3. Выберите GigaAM v3 для русской речи либо Parakeet v3 для многоязычных записей и пунктуации.
4. Включите «Разделять по спикерам». Выберите число участников, если оно известно, либо «Авто».
5. Укажите папку сохранения и нажмите «Расшифровать».
6. После обработки при необходимости введите имена спикеров и нажмите «Сохранить имена». Нумерация соответствует первому появлению голосов, а не ролям участников.

Каждая запись получает собственную папку с основными файлами и вариантом без имён спикеров:

- `transcript.txt` — обычный текст с временными метками и спикерами.
- `transcript.md` — тот же текст в Markdown.
- `transcript.srt` — субтитры с началом и концом каждой реплики, именами спикеров и отметками перекрытий.
- `transcript.json` — структурированный результат для повторного открытия.
- `transcript.no-speakers.txt/.md/.srt` — та же транскрипция без имён спикеров; повторный ASR не нужен.
- `voiceprints.npz` — локальные признаки голосов для повторного распределения без повторного распознавания. Не передавайте их вместе с установщиком.

Нажмите на время у реплики, чтобы прослушать соответствующее место исходной записи. При повторном открытии JSON можно снова выбрать исходную запись для прослушивания.

`[?]` означает неуверенное определение голоса, `[перекрытие]` — одновременную речь. Приложение определяет голоса, но не знает имён участников. Автоопределение числа спикеров и наложения голосов могут ошибаться. Фиксированное число участников полезно для обычных встреч. Обе модели выдают пунктуацию самостоятельно; отдельной генеративной постобработки нет. GigaAM использует E2E-версию из кэша вашего исходного распознавателя.

## Редактор транскрипции

Нажмите «Редактировать», чтобы менять текст реплик и выбирать другого спикера в каждой реплике. Если участник не был выделен автоматически, нажмите «Добавить спикера». Временные метки не меняются. Для сохранения нажмите «Сохранить правки» или ⌘S: обновятся TXT, Markdown, SRT и JSON.

«Найти и заменить» (⌘F) показывает число совпадений и первые восемь изменяемых реплик. Можно учитывать регистр и искать только целые слова. Замена выполняется буквально: специальные символы не считаются регулярным выражением. Изменения можно отменять и повторять кнопками со стрелками либо ⌘Z / ⇧⌘Z. В обычных текстовых полях эти сочетания отменяют ввод поля. История правок ограничена последними 100 действиями и действует до закрытия транскрипции.

Пары замен можно добавить в локальный словарь и применять к текущей транскрипции. Автоматическое применение к следующим записям включается отдельно в словаре; по умолчанию выключено. Правила применяются по порядку. Например, «редми → README» или «виктория метрикс → VictoriaMetrics». Проверьте заменённые реплики: словарь исправляет совпадения, но не понимает контекст.

Перед первым сохранением правок сохраняются файлы `transcript.original.*`. Исходную версию можно вернуть через кнопку в словаре и также отменить восстановление. Сохранённые правки и дополнительные метаданные остаются в JSON после повторного открытия. Перед закрытием приложения или переходом к другой записи приложение предлагает сохранить несохранённые изменения.

Поле поиска и фильтр «Требуют проверки» помогают найти нужные места. Кнопка с галочкой у реплики отмечает её проверенной и убирает из списка сомнительных участков. Нажатие на время запускает прослушивание исходной записи.

## Диаризация и исправление спикеров

Разделение голосов выполняет Pyannote + CAM++, независимо от модели текста. Автоопределение сравнивает устойчивые голосовые группы и отбрасывает маленькие шумные кластеры. Для известных встреч можно указать число участников.

В 1.2 текст распознаётся одним проходом, затем слова сопоставляются с временными участками речи. Это предотвращает дублирование одного аудио при перекрывающихся сегментах. Короткие фрагменты привязываются также к устойчивому локальному голосу. Таймкоды GigaAM получены из RNNT-эмиссий и приблизительны; возле смены голоса возможны ошибки. При неоднозначных наложениях голос может быть помечен как «Спикер не определён», вместо уверенного назначения человеку. Результат нельзя считать безошибочной разметкой.

Кнопка «Спикеры» позволяет объединить целые группы с отменой или пересчитать распределение с другим числом участников. При пересчёте текст и таймкоды сохраняются, имена нужно проверить заново. Для старых файлов без voiceprints потребуется исходная запись. Если одна группа содержит двух людей, исправляйте отдельные реплики, а не объединяйте её целиком.

Есть ожидаемый язык «Русский», «Английский» и «Русский + английский». Parakeet получает подсказку языка, но это не гарантирует отсутствия чужих слов. Несоответствия отмечаются для проверки; текст автоматически не подменяется. GigaAM ориентирован на русский язык: для английской речи используйте Parakeet.

## Длинные записи

Аудио преобразуется в временный WAV на диске, с RF64 для записей больше 4 ГБ. Затем читается блоками по пять минут с контекстом по краям. Каждый речевой фрагмент для распознавания ограничен 25 секундами и по возможности разрезается по тихому месту. В память не загружается вся запись.

Образы голосов объединяются **по всей записи** после обработки блоков. Номера спикеров сохраняются между частями. Для кластеризации используются не более 1200 репрезентативных образцов; число текстовых реплик не ограничено этим значением. Тихие промежутки, пропущенные сегментацией, дополнительно проверяются распознаванием.

Нужно свободное место для временного аудио: примерно 115 МБ на час записи, плюс исходник и итоговый текст. Исходный файл не меняется. Кнопка отмены останавливает обработку и удаляет временные данные. Приложение не возобновляет прерванную обработку с середины.

## Что входит в сборку

- Нативное окно SwiftUI, без локального веб-сервера.
- GigaAM v3 E2E RNNT ONNX — локальный экспорт уже скачанной модели с пунктуацией.
- Parakeet TDT 0.6B v3 Q8_0 GGUF — копия модели из кэша Handy; сам Handy для работы не нужен.
- Pyannote segmentation 3.0 и CAM++ — сегментация и представления голосов через Sherpa-ONNX.
- Silero VAD — определение речи в режиме без диаризации.
- ONNX Runtime, transcribe.cpp, Python и все необходимые пакеты.
- FFmpeg и FFprobe с необходимыми библиотеками.

Во время работы нет загрузки моделей, сетевых API и отправки аудио. Доступ рабочего процесса к сети дополнительно запрещён средствами macOS. Parakeet использует доступный локальный backend (Metal или CPU); GigaAM ONNX и диаризация работают на CPU.

## Установка и передача другим

Готовый DMG лежит в `dist/release-1.2/Голоса-1.2.0-AppleSilicon.dmg`. Передавайте именно DMG либо целиком папку `.app`: движки внутри, модели загружаются отдельно или импортируются. Handy не нужен.

Целевая сборка — macOS 14 и новее, Apple Silicon (M1/M2/M3/M4 и более новые). Первая сборка проверена на текущем Mac Apple M4; на старых версиях macOS отдельная проверка не проводилась. Intel и Windows этой сборкой не поддерживаются.

Сборка подписана локальной ad-hoc подписью, без сертификата Apple Developer и нотарификации. После скачивания на другом Mac macOS может попросить разрешить запуск: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» после первой попытки запуска. Для обычного выпуска без такого шага потребуется сертификат Developer ID и нотарификация Apple.

Атрибуция сторонних компонентов находится в `THIRD_PARTY.md` и `licenses/`, они также включены внутрь приложения.

## Разработка и повторная сборка

Исходники приложения находятся в `macos/`, обработчика — в `backend/`. Все комментарии и документация на русском языке. Модели лежат в `models/`; приложение не скачивает их самостоятельно.

Для сборки нужны Command Line Tools/Xcode со Swift, Python 3.14, `uv` и зависимости из `requirements.txt`:

```sh
uv venv --python 3.14 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python scripts/build_media.py
PYTHONPATH=. .venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/check_editor.py
.venv/bin/python scripts/build.py --python .venv/bin/python --dmg
```

Сборщик упаковывает Python-движок через PyInstaller, включает модели и самостоятельно собранный FFmpeg, компилирует SwiftUI и создаёт DMG. Для пересборки только интерфейса можно добавить `--skip-engine`. Готовое приложение не зависит от путей сборочного компьютера и установленного Homebrew/Python.

Основные этапы движка: конвертация → чтение блоков → сегментация/речь → распознавание → общая кластеризация голосов → TXT/MD/SRT/JSON. Окно получает прогресс через JSON-строки дочернего процесса. Рабочие процессы завершаются при отмене; выход во время обработки предлагает дождаться завершения или остановить обработку.
