# Сайт «Голоса»

Адрес: https://dmitryturin-art.github.io/local-transcriber/

GitHub Pages публикует ветку `main`, папку `/docs`. Файл `.nojekyll` позволяет отдать HTML/CSS/JS без генератора сайта. Для обновления достаточно изменить файлы и отправить коммит в `main`.

- `index.html` — содержание страницы, кнопки скачивания, FAQ и метаданные для ссылок.
- `style.css` — оформление, адаптация экранов и анимации.
- `app.js` — вымышленное демо и визуализация волны.
- `site-assets/` — логотип, безопасный снимок интерфейса и изображение для предпросмотра ссылок.

Никакие записи пользователей на сайт не загружаются. Экспорт демо создаёт текст из вымышленного диалога в браузере. Копирование и скачивание происходят только по нажатию соответствующей кнопки. На сайте нет аналитики, микрофона или серверного распознавания.

При новом выпуске приложения обновите номер версии и все ссылки на установщик в `index.html`. Не добавляйте скриншоты с реальными клиентскими данными.

Для локального просмотра можно запустить сервер из корня проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

Проверены таймлайн, воспроизведение демо, редактирование имён, виды текста, копирование, TXT/Markdown/SRT, переключение моделей, изображение интерфейса, FAQ, сокращённая анимация и ширины экрана 320–1440 пикселей.
